# WebSec Copilot

> **AI-Powered Security Copilot for Modern Web Applications**

## 🎙️ Built for No Hands: The Wispr Challenge (WeMakeDevs x Wispr Flow)

- **Track:** Track 1 — Builders (For Developers)
- **The Problem in My Own Work:** As a full-stack developer and security researcher shipping apps rapidly with AI tools, manually auditing every deployment for broken security headers, TLS misconfigurations, leaked JS secrets, vulnerable npm packages, and CVEs takes hours of repetitive work.
- **How Wispr Flow Was Used:** Built using a voice-first workflow with Wispr Flow—dictating multi-source scanning specs, AI remediation prompt templates, Convex backend orchestration logic, UI component structures, and project documentation hands-free instead of typing.
- **Real Result Produced:** Audited live production web apps and GitHub repositories in seconds, generating prioritized remediation code and exportable PDF/Markdown security audit reports.

## Overview

WebSec Copilot is an AI-driven security auditing platform designed for modern developers building applications at high speed.

In today’s development landscape, AI has made it easier than ever to build software quickly. However, security is often overlooked in this process. WebSec Copilot addresses this gap by acting as a security copilot — helping developers identify, understand, and fix vulnerabilities in their applications in real time.

This project was built using AI-assisted development workflows with Antigravity, focusing on rapid iteration, intelligent analysis, and practical security solutions.

## Problem

As development becomes faster with AI-assisted workflows, security is often ignored. This leads to:

* Insecure applications being deployed
* Exposed APIs and sensitive data
* Lack of awareness among developers about real-world threats

Most developers focus on building features, not securing them.

## Solution

WebSec Copilot simplifies security by integrating it directly into the development workflow. Instead of requiring deep cybersecurity knowledge, it provides:

* **Clear identification** of vulnerabilities
* **Simple explanations** of risks
* **Actionable steps** to fix issues

It transforms security from a complex task into an accessible and practical process.

* 🌐 **Websites:** Headers, cookies, security configurations

## How It Works

WebSec Copilot follows a structured pipeline:

1.  **Input is provided** (URL, repository, code, or package).
2.  The system **analyzes multiple layers** of the target.
3.  **AI processes the findings** and identifies vulnerabilities.
4.  Each issue is **explained in simple terms**.
5.  **Remediation steps** are generated for developers.

This ensures that users not only detect issues but also understand and fix them effectively.

## AI Usage

AI is used throughout the platform to:
* Analyze patterns and detect vulnerabilities.
* Explain complex security issues in simple language.
* Generate safe and practical remediation steps.
* Enhance findings with contextual understanding.

The system is designed to make security accessible even for developers without a cybersecurity background.
